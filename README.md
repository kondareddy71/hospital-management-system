# 🏥 Hospital Management System

## 📌 About the Project

The **Hospital Management System** is my final-year academic project, developed to simplify and organize hospital-related activities through a web-based application.

The project focuses on managing hospital information and providing a user-friendly interface for common hospital operations. It also includes an ABHA-related module to demonstrate digital health identity workflows.

This project helped me apply my programming knowledge to a practical healthcare management use case and gain hands-on experience in web application development.

## 🎯 Objectives

- Simplify hospital-related information management.
- Provide a user-friendly interface for hospital operations.
- Organize appointment, doctor, and patient-related workflows.
- Explore digital health identity workflows through the ABHA module.
- Develop practical skills in backend development and application integration.

## ✨ Key Features

- **User Registration and Login:** User account access and authentication workflows.
- **Dashboard:** An interface for accessing hospital-related information.
- **Doctor Management:** Pages for viewing and managing doctor information.
- **Appointment Management:** Support for appointment-related workflows.
- **Patient History:** A section for accessing patient history information.
- **ABHA Module:** An additional module for ABHA-related registration and dashboard workflows.

*Note: The features listed above describe the implemented project structure; actual functionality depends on the application's current implementation.*

## 🛠️ Technologies Used

- **Backend:** Node.js, Express.js
- **Frontend:** EJS, HTML, CSS, JavaScript
- **Package Management:** npm
- **Version Control:** Git and GitHub

## 🚀 Getting Started

### Prerequisites

- Node.js and npm installed
- Git installed

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/kondareddy71/hospital-management-system.git
   ```

2. Open the project directory:

   ```bash
   cd hospital-management-system
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the application using the start script configured in `package.json`:

   ```bash
   npm start
   ```

   If the project uses a different start script, check `package.json` and use the appropriate command.

5. Open the local URL shown in your terminal or configured in the application.
